这个项目用于测定图片里的叶片面积。我最初认为将园艺专业知识与计算机结合起来，可以极大节省人力，为了探索这种结合，我选择了这个项目作为切入点。图片里的参照物选取了蓝色纸方块，因为这是在我身边最容易获取的材料。这个项目输入为：叶片和2cm蓝色方块图片，输出为：叶片的预测面积。

运行准备：环境条件要求如下：
numpy==2.5.3
opencv-python==5.0.0.93
pandas==3.0.6
matplotlib==3.11.2
将被测定图片图片放入images文件夹，并以"leaf_"为前缀便于筛选。直接运行以下代码：
git clone <我的GitHub/Gitee仓库链接>
cd AI_study

pip install -r requirements.txt
和
python guoqing5_batch_pandas.py
最终自动生成excel结果文件

此前，使用2cm，3cm，4cm蓝色方块进行独立检验时，手动切割蓝色方块存在误差，在此基础上，2cm、3cm、4cm方块间（以2cm为基准）面积绝对误差小于2.60%；使用2cm方块定标前提下，代码跑测单张叶片像素面积小于ImageJ单张手动勾勒叶片像素面积，误差约为2.2336%

目前局限：单个组别内相机位置固定，否则一组照片内像素比例尺完全失效；由于对单个正面叶片照片进行测定，无法考虑到卷曲叶面；难以测定枯黄叶片照片：由于条件因素，只有暖色调光照。若叶片枯黄，使用掩膜扩大阈值或者单独增加黄色阈值，极易把背景的暖色噪点误判为叶片，从而造成误差；蓝色方块反光，反光位被测定为背景。由于摄影位的固定，若改变光照方向，则阴影区域又造成一部分掩膜误差。

该项目使用AI作辅导和引领作用，由本人搭建，修改并测试代码，测试图片均为真实拍摄。
